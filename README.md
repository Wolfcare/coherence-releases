# Coherence releases

Downloads for **Coherence**, a multi-mic time and phase alignment plug-in (AU + VST3) by Obscura Lux.

Go to **[Releases](../../releases/latest)** and download `Coherence-<version>.dmg`
(macOS 12 or later, Apple Silicon and Intel).

Coherence checks this page for new versions and can install them by itself (Settings ▸ Updates).
Each release includes `coherence-update.json`, which lists the update package with its size and
SHA-256 hash, and `coherence-update.json.sig`, an RSA signature of that file. Coherence installs an
update only if the signature, the hash and the Apple Developer ID code signature all check out.
